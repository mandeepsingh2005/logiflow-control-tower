# 🚚 LogiFlow – Supply Chain Control Tower

LogiFlow is a web-based dashboard that provides real-time shipment tracking, delay detection, and exception-based alerts for SMEs.

## 🌟 Features
- Real-time shipment tracking
- Smart delay detection
- Exception-based alerts
- Interactive map (Leaflet.js)
- Analytics dashboard (Chart.js)
- Dark/Light mode

## 🛠 Tech Stack
- HTML, Tailwind CSS
- JavaScript (ES Modules)
- Leaflet.js
- Chart.js

## 🚀 How to Run
1. Clone the repo
2. Open in VS Code
3. Run using Live Server

## 🎯 Demo Flow
- Detect delay → Alert → Map → Resolution

## 🔮 Future Scope
- AI-based predictions (Google Gemini)
- Real API integration
